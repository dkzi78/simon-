## 1. Score Repository — `src/storage/scores.ts`

```ts
export interface Scores { readonly bestScore: number; readonly lastScore: number }

export interface ScoreRepository {
  readonly available: boolean;      // false after any storage failure
  read(): Scores;
  record(completedRounds: number): Scores; // lastScore = n, bestScore = max(best, n)
}

export function parseScores(raw: string | null): Scores;          // pure, tested
export function createScoreRepository(getStorage: () => Storage): ScoreRepository;
```

- **מפתח:** `simon:simon-:scores:v1` (שם ה־Repository הוא `simon-`), כקבוע ב־`config.ts`.
- **פורמט:** JSON אחד `{"bestScore":n,"lastScore":n}` — כתיבת `setItem` אחת לשני הערכים.
- **Validation:** כל שדה חייב להיות מספר שלם 0–10 (`Number.isInteger` ובדיקת טווח). שדה חסר / לא מספר / עשרוני / מחוץ לטווח → 0, בלי לגעת בשדה התקין השני. JSON פגום או ערך שאינו אובייקט → שני אפסים.
- **Fallback:** הגישה ל־`window.localStorage` עצמה (דרך `getStorage`), ‏`getItem` ו־`setItem` עטופות ב־`try/catch`. כל כשל → `available = false`, והערכים ממשיכים להישמר במשתנה בזיכרון. מאותו רגע הקריאה מחזירה את ערכי הזיכרון.
- **השיא נקרא מחדש לפני כל עדכון** (`record` קורא מהאחסון ואז כותב), לפי ARCHITECTURE סעיף 3.
- `record` משמש גם להשלמת שלב וגם להפסד: בשני המקרים `lastScore = completedRounds`, והשיא לא יורד אף פעם. התחלת משחק אינה קוראת ל־`record`.
- בקוד הייצור: `createScoreRepository(() => window.localStorage)`. בבדיקות: אחסון מדומה (Map) או אחסון שזורק שגיאה.

## 2. Controller — השהיה משתי סיבות וכתיבת ניקוד

המשחק רץ רק כשהמשתמש **במסך הבית וגם** המסמך גלוי. במקום `pause()`/`resume()` הציבוריים:

```ts
setScreen(screen: 'home' | 'about'): void;
setDocumentHidden(hidden: boolean): void;
```

שתיהן מעדכנות דגל פנימי ואז קוראות ל־`sync()`:

- אם אסור לרוץ (`about` או מוסתר) → ההשהיה הקיימת: `engine.pause`, ‏`scheduler.cancel()`, ניקוי משוב לחיצה, כיבוי אור. במצבי `idle`, ‏`lost`, ‏`won` — `engine.pause` לא משנה דבר, ולכן אין „חידוש” של משחק שהסתיים.
- אם מותר לרוץ והמצב `paused` → ה־`resume` הקיים: `audio.unlock()`, ‏`engine.resume`, הצגת כל רצף השלב מחדש.
- כך: הסתרה בזמן שהמשתמש באודות וחזרה לגלוי משאירה אותו מושהה; רק חזרה לבית ממשיכה.

**כתיבת ניקוד** בתוך `press()`, מיד אחרי מעבר המצב ולפני ה־Side Effects האחרים:

- `roundComplete` או `won` → `scores.record(game.completedRounds)`.
- `lost` → `scores.record(game.completedRounds)` (0 אם עוד לא הושלם שלב).

**ViewState** מקבל שדה נוסף `storageAvailable` מ־`scores.available`. ה־Repository מוזרק ל־`createController` כפרמטר.

## 3. ניווט — `routes.ts`, ‏`bottom-nav.ts`, ‏`main.ts`

- `parseRoute`: ‏`''`, ‏`'#'`, ‏`'#/'` → `home`; ‏`'#/about'` → `about`; כל דבר אחר → `null`.
- ב־`main.ts`, בטעינה וב־`hashchange`: אם `null` → `location.replace('#/')` (נרמול לבית בלי להוסיף רשומת היסטוריה) ויציאה; אחרת מציגים את המסך המתאים (`hidden` על השני), מעדכנים את הניווט, וקוראים ל־`controller.setScreen(route)`. בכניסה לאודות — `aboutView.render(scores.read(), scores.available)` כדי להציג ערכים עדכניים.
- Back של הדפדפן עובד מעצמו: כל מעבר בין `#/` ל־`#/about` הוא רשומת היסטוריה, ו־`hashchange` מטפל בו באותה דרך.
- `visibilitychange` → `controller.setDocumentHidden(document.hidden)`.
- **Bottom Navigation:** ‏`<nav>` עם שני קישורים אמיתיים `<a href="#/">` ו־`<a href="#/about">`, בסדר DOM „בית” ואז „אודות” (ב־RTL „בית” מימין). מעל כל תווית אייקון Outline (בית / מידע ‏ⓘ) בקו 2 px, נבנה ב־`createElementNS` בלי `innerHTML`. הפריט הפעיל: `aria-current="page"`, צבע כחול `#0A9FF5` וקו תחתון רחב ומעוגל; הלא־פעיל `#9AA7B8`. מפריד אנכי בין הפריטים וקו הפרדה עליון. כל פריט לפחות 48 px גובה.
- **שמע בחזרה לבית:** בלחיצה על „בית” קוראים ל־`audio.unlock()` ישירות מתוך ה־click (Gesture). חזרה ב־Back אינה Gesture — אם הדפדפן חוסם שמע, המשחק ממשיך חזותית, כפי שכבר מוגדר בארכיטקטורה.
- `#/` בבית אינו מוסיף ניווט כפול: לחיצה על הפריט הפעיל לא משנה כלום.

## 4. מסך אודות — `about-view.ts`

נבנה פעם אחת; `render(scores, storageAvailable)` מעדכן רק את המספרים וההודעה. מלמעלה למטה:

1. `h1` מרכזי „אודות” — אותו סגנון כמו „סיימון” בבית, עם אותו קו הפרדה דק מתחתיו.
2. **אזור לוגו** אופקי: משטח כהה מורם; בתוכו `<img src={logo.svg} alt="">` (סמל עגול) ולצדו המילה „סיימון” כטקסט HTML גדול ב־Heebo 800. התמונה דקורטיבית; לאזור כולו `role="img"` עם `aria-label="סיימון"`.
3. פסקת תיאור מיושרת לימין: „סיימון הוא משחק זיכרון עם אורות וצלילים. חזור על הרצף ונסה להשלים 10 שלבים.”
4. `h2` „איך משחקים?” (22/30, 700), מיושר לימין.
5. חמש שורות הוראות נפרדות (16/24): „לחץ על התחל.”, „צפה ברצף והקש על הצבעים באותו סדר.”, „בכל שלב נוסף צבע.”, „טעות אחת מסיימת את המשחק.”, „אין הגבלת זמן.”
6. שני כרטיסים אופקיים זה מתחת לזה: „שיא אישי” ו„תוצאת המשחק האחרון”. תווית מימין (14/20, 500), מספר גדול ומודגש משמאל (`justify-content: space-between`). המספר נכתב ב־`textContent` בלבד.
7. אם האחסון אינו זמין — שורה קצרה „לא ניתן לשמור תוצאות במכשיר זה”.

כל הטקסטים בעברית מוגדרים ב־`config.ts`. תוכן ארוך נגלל, ולא מוסתר מאחורי הניווט.

## 9. ADRs להוספה ב־ARCHITECTURE.md

- **ADR-4: לוגו כסמל SVG ושם בטקסט HTML** — הקשר: SVG כתמונה אינו טוען את Heebo, וטקסט עברי בתוכו ייראה שונה בין מכשירים. החלטה: `logo.svg` מכיל רק את הסמל העגול; „סיימון” מוצג לצדו כטקסט HTML. השלכות: עברית עקבית; אותו סמל משמש לאייקוני ההתקנה באבן דרך 4.
- **ADR-5: השהיה משתי סיבות** — הקשר: המשחק צריך להיעצר גם באודות וגם כשהמסמך מוסתר, ולהמשיך רק כששתיהן מתבטלות. החלטה: ה־Controller שומר את המסך הנוכחי ואת מצב ההסתרה, וממשיך רק כשהמשתמש בבית והמסמך גלוי. השלכות: הסתרה וחזרה בזמן שהייה באודות אינן מפעילות את המשחק ברקע.

## 11. בדיקה ידנית (בדפדפן בגודל מובייל, 375×812)

- **מבנה ועיצוב:** בית ואודות כהים, תואמים למבנה ה־Mockup; לוגו עגול + „סיימון”; הוראות בשורות נפרדות; כרטיסים עם תווית מימין ומספר משמאל; התוכן נגלל ואינו מוסתר מאחורי הניווט; אין גלילה אופקית; פריטי ניווט ≥ 48 px.
- **ניווט:** לחיצה על „אודות” / „בית” ו־Back מחליפים מסך וסימון פעיל. `#/xyz` מנורמל לבית.
- **השהיה:** מעבר לאודות (א) בזמן הצגת רצף, (ב) אחרי קלט חלקי, (ג) בהפסקה בין שלבים — הצליל נעצר מיד; בחזרה מוצג אותו רצף מתחילתו (אותם צבעים, אותו שלב), וקלט חלקי לא נשמר.
- **מצבים שאינם פעילים:** מעבר לאודות וחזרה ממצב „התחל”, „המשחק הסתיים” ו„כל הכבוד” — המסך חוזר כפי שהיה, בלי משחק חדש.
- **הסתרה באודות:** משחק פעיל → אודות → החלפת טאב וחזרה — נשאר מושהה באודות; רק חזרה לבית מציגה את הרצף.
- **ניקוד:** השלמת כמה שלבים → האודות מציגים תוצאה ושיא מעודכנים; הפסד מיידי במשחק חדש → תוצאה 0, השיא נשמר.
